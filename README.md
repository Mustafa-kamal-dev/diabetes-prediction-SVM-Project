# 🩺 Diabetes Prediction using Support Vector Machine (SVM)

### 📘 Project Overview
This project aims to predict whether a person is **diabetic or not** using a **Machine Learning model (SVM)**.  
The model is trained on medical data containing important health attributes such as glucose level, blood pressure, BMI, insulin, and age.  
This project demonstrates skills in **data preprocessing, model building, feature scaling, and evaluation** using Python.

---

## 🎯 Objective
To develop a **predictive system** that can help identify the likelihood of diabetes based on medical parameters.  
The project focuses on using **Support Vector Machine (SVM)** — one of the most powerful algorithms for binary classification.

---

## 🧠 Workflow

1. **Data Collection & Loading**  
   - Loaded the Diabetes dataset into a Pandas DataFrame.  
   - Explored the dataset using basic statistics and visualizations.

2. **Data Preprocessing**  
   - Handled missing values and normalized the data using `StandardScaler`.

3. **Model Training**  
   - Trained a **Support Vector Machine (SVM)** classifier from Scikit-learn.  
   - Split the data into training and testing sets to evaluate performance.

4. **Model Evaluation**  
   - Calculated the **accuracy score** and **confusion matrix**.  
   - Verified results using test samples.

5. **Prediction System**  
   - Created an input system that predicts diabetes for any custom data point.
